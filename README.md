# Weald & Stone

Concept demo by [Northlight Studio](https://northlight-studio-chi.vercel.app) for the
Kent construction niche. **Weald & Stone is a fictional builder** — it exists so a real
Kent building firm can see what their own site would look like.

- **Live:** _(add the Vercel URL after first deploy)_
- **Stack:** single-file static HTML/CSS/JS. No build step, no dependencies.
- **Deploy:** Vercel, import this repo, no configuration needed.

## Imagery

Seven photographs in `assets/`, generated in Higgsfield (Soul v2) to one warm neutral
grade pinned to the palette. They are **not** in git history from the sandbox — the
agent environment can't reach the Higgsfield CDN. Regenerate or re-pull with
`../fetch-images.sh` from the parent folder.

If any image in `assets/` is a bright orange "PLACEHOLDER" tile, the fetch step has not
been run and this site must not be deployed.
